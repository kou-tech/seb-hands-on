# Sapporo Engineer Base ハンズオン

プログラミング未経験者・初学者を対象に、1日でブログを作ってインターネットに公開するハンズオンの教材リポジトリです。

参加者は最後に、スマホからも開ける自分のブログのURLを持ち帰ります。

## このリポジトリの中身

| パス | 内容 | 読む人 |
|------|------|--------|
| [guides/](./guides/README.md) | ハンズオンガイド 01〜08 と図 | 参加者・メンター |

## ハンズオンの概要

### 対象者

- プログラミング未経験者
- プログラミング初学者
- 学生

### 目的

実際に手を動かしてプログラミングを経験し、動くアプリケーションを作って公開するところまでを体験していただきます。

## 作るもの

記事を投稿できるシンプルなブログです。

- 記事を書いて公開する（タイトル・公開日・本文）
- 記事を読む
- 記事を編集する
- 記事を削除する
- 月別アーカイブで絞り込む
- インターネットに公開する

### 画面構成

| 画面 | ファイル | 内容 |
|------|---------|------|
| 記事一覧 | `articles/index.blade.php` | タイトルの一覧、月別アーカイブ、新規作成ボタン |
| 記事ページ | `articles/show.blade.php` | 本文を読む。編集ボタン |
| 新規作成 | `articles/create.blade.php` | タイトル・公開日・本文の入力 |
| 編集 | `articles/edit.blade.php` | 内容の書き換えと削除 |

### 実装しないもの

ログイン機能は実装しません。発展課題（[08.md](./guides/08.md)）で扱います。
