# 発展課題に挑戦しよう

日記アプリが完成したあなたへ。さらにスキルアップしたい方向けの発展課題を用意しました。

自分のペースで挑戦してみてください！

## この課題について

発展課題は、ハンズオンで学んだ内容を応用するものです。

- **中級**: 今回の知識で挑戦できる課題
- **上級**: 新しい概念を学びながら挑戦する課題

すべてを完了する必要はありません。興味のある課題から取り組んでみましょう。

> **メンター視点**
> - 発展課題は自習用です。ハンズオン時間内に終わらなくても問題ありません
> - 詰まったときは、公式ドキュメントや検索を活用することも学習の一部です
> - 完成度より「挑戦すること」を大切にしてください


## 中級課題

今回学んだ内容の応用で取り組める課題です。


### 課題1: 日記にタイトルを追加する

日記に「タイトル」欄を追加して、一覧画面でタイトルを表示できるようにしましょう。

#### やること

1. マイグレーションを作成して、`diaries` テーブルに `title` カラムを追加
2. `Diary` モデルの `$fillable` に `title` を追加
3. 新規作成・編集画面にタイトル入力欄を追加
4. 一覧画面でタイトルを表示

#### ヒント

- 新しいマイグレーションを作成するコマンド: `php artisan make:migration add_title_to_diaries_table`
- マイグレーションで `$table->string('title')->nullable();` を追加
- `nullable()` をつけると、タイトルなしでも保存できます

> **メンター視点**
> - この課題は、04.md で学んだ「マイグレーション → モデル → ビュー」の流れを復習できます
> - 既存のテーブルにカラムを追加する方法を学べます

### 課題2: 天気を記録する

日記にその日の天気を記録できるようにしましょう。

#### やること

1. `diaries` テーブルに `weather` カラムを追加
2. 新規作成・編集画面に天気の選択欄（セレクトボックス）を追加
3. 一覧画面で天気アイコンを表示

#### 天気の選択肢の例

```
晴れ ☀️
曇り ☁️
雨 🌧️
雪 ❄️
```

#### ヒント

- HTMLのセレクトボックス: `<select name="weather">...</select>`
- 選択肢は `<option value="sunny">晴れ ☀️</option>` のように書きます
- 絵文字はそのままコードに書けます

> **メンター視点**
> - セレクトボックスの使い方を学べます
> - 決まった選択肢から選ばせるUIパターンです

### 課題3: キーワード検索を追加する

日記の内容をキーワードで検索できるようにしましょう。

#### やること

1. 一覧画面に検索フォームを追加
2. コントローラーで検索キーワードを受け取る
3. キーワードを含む日記だけを表示

#### ヒント

- 検索フォームは `<form method="GET">` で作成
- コントローラーで `$request->query('keyword')` でキーワードを取得
- Eloquentの `where('content', 'like', "%{$keyword}%")` で部分一致検索

#### 参考: 検索のイメージ

```
検索キーワード: [ラーメン    ] [検索]

→ 「ラーメン」を含む日記だけが表示される
```

> **メンター視点**
> - GETパラメータの扱い方を学べます
> - SQLのLIKE検索の概念を説明すると良いでしょう

### 課題4: お気に入り機能を追加する

日記にお気に入り（スター）をつけられるようにしましょう。

#### やること

1. `diaries` テーブルに `is_favorite` カラム（boolean型）を追加
2. 一覧画面にスターアイコンを表示
3. スターをクリックしたらお気に入りを切り替え
4. お気に入りだけを表示するフィルター機能

#### ヒント

- `$table->boolean('is_favorite')->default(false);`
- スターアイコン: ⭐（お気に入り）、☆（通常）
- お気に入りの切り替えは、新しいルートとコントローラーメソッドが必要

> **メンター視点**
> - boolean型の使い方を学べます
> - トグル（ON/OFF切り替え）のUIパターンです

### 課題5: 日記の並べ替え機能を追加する

日記の表示順を切り替えられるようにしましょう。

#### 並べ替えの選択肢

- 日付が新しい順（デフォルト）
- 日付が古い順
- 作成日が新しい順
- 作成日が古い順

#### ヒント

- 並べ替えオプションをセレクトボックスで選択
- `orderBy('date', 'desc')` や `orderBy('created_at', 'asc')` で並べ替え
- URLパラメータで並べ替え条件を渡す

> **メンター視点**
> - ORDER BY の概念を学べます
> - `date` と `created_at` の違いを説明すると良いでしょう

## 上級課題

新しい概念を学びながら挑戦する課題です。

### 課題6: タグ機能を追加する

日記にタグをつけて分類できるようにしましょう。

#### 概要

```
今日の日記
タグ: #仕事 #ミーティング #アイデア
```

#### 学ぶこと

- **多対多リレーション**: 1つの日記に複数のタグ、1つのタグに複数の日記
- **中間テーブル**: `diary_tag` テーブルで関連を管理
- **belongsToMany**: Eloquentの多対多リレーション

#### 必要なテーブル

```
tags テーブル
- id
- name

diary_tag テーブル（中間テーブル）
- diary_id
- tag_id
```

#### 参考リンク

- Laravel公式: [Eloquent リレーション - 多対多](https://readouble.com/laravel/11.x/ja/eloquent-relationships.html#many-to-many)

> **メンター視点**
> - データベース設計の概念を学べます
> - 多対多リレーションは実務でもよく使うパターンです

### 課題7: 画像添付機能を追加する

日記に写真を添付できるようにしましょう。

#### 概要

- 新規作成・編集画面で画像をアップロード
- 日記と一緒に画像を表示
- 画像は `storage/app/public` に保存

#### 学ぶこと

- **ファイルアップロード**: `$request->file('image')`
- **ストレージ**: Laravelのファイル保存機能
- **シンボリックリンク**: `php artisan storage:link`

#### ヒント

- フォームに `enctype="multipart/form-data"` が必要
- `$request->file('image')->store('diaries', 'public')` で保存
- 画像パスをデータベースに保存

#### 参考リンク

- Laravel公式: [ファイルストレージ](https://readouble.com/laravel/11.x/ja/filesystem.html)

> **メンター視点**
> - ファイルアップロードはWebアプリの基本機能です
> - セキュリティ（ファイルタイプの検証）についても触れると良いでしょう

### 課題8: ログイン機能を追加する

自分だけが見られる日記帳にしましょう。

#### 概要

- ユーザー登録・ログイン・ログアウト機能
- ログインしないと日記が見られない
- 自分の日記だけが表示される

#### 学ぶこと

- **認証（Authentication）**: ユーザーの識別
- **Laravel Breeze**: 認証機能のスターターキット
- **ミドルウェア**: ログイン必須のルート設定

#### インストール方法

```bash
composer require laravel/breeze --dev
php artisan breeze:install blade
npm install && npm run build
php artisan migrate
```

#### 参考リンク

- Laravel公式: [Laravel Breeze](https://readouble.com/laravel/11.x/ja/starter-kits.html#laravel-breeze)

> **メンター視点**
> - 認証は多くのWebアプリで必須の機能です
> - Breezeを使うと、認証機能を素早く導入できます
> - 導入後のコードを読んで、仕組みを理解することが大切です

### 課題9: Markdown対応にする

日記の内容をMarkdown記法で書けるようにしましょう。

#### 概要

```markdown
# 今日のハイライト

- ランチに **美味しいパスタ** を食べた
- 新しい本を読み始めた

> 明日も頑張ろう！
```

↓ 表示時はHTMLに変換

#### 学ぶこと

- **Composerパッケージ**: 外部ライブラリの導入
- **Markdownパーサー**: テキストをHTMLに変換
- **XSS対策**: HTMLのサニタイズ

#### おすすめライブラリ

- `league/commonmark`: PHP用Markdownパーサー

```bash
composer require league/commonmark
```

> **メンター視点**
> - 外部ライブラリを導入する流れを学べます
> - セキュリティ（XSS）についても重要な学びがあります

## 課題に取り組むときのアドバイス

### 1. 小さく始める

一度に全部作ろうとせず、小さな部分から始めましょう。

```
❌ いきなり完璧なタグ機能を作ろうとする
✅ まずタグのテーブルだけ作ってみる
```

### 2. エラーを恐れない

エラーは「何が問題か教えてくれるメッセージ」です。

```
エラーが出た
    ↓
エラーメッセージを読む
    ↓
検索してみる
    ↓
解決！（これが一番の学び）
```

### 3. 動いたらコミット

小さな単位で動作確認し、動いたらGitでコミットしましょう。

```bash
git add .
git commit -m "タイトル機能を追加"
```

こうすると、失敗しても戻れます。

### 4. 調べ方を覚える

プログラミングは「調べながら作る」のが普通です。

- 公式ドキュメントを読む
- エラーメッセージで検索する
- 動くコードを参考にする
