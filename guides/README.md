# Laravel ハンズオンガイド 〜1日で自分のブログを作って公開する〜

プログラミングがはじめての方のための、Laravel で自分のブログを作り、インターネットに公開するガイドです。

コピー＆ペーストで進められるように書いてあります。全部を理解できなくても大丈夫。
最後には、スマホからも開ける自分のブログのURLが手に入ります。

## この日のゴール

1. 動く Webアプリケーションを、自分の手で作る
2. インターネットに公開して、自分のURLを手に入れる
3. デザインや文言を自分色にカスタマイズする

## 作るもの

記事の投稿・閲覧・編集・削除・月別アーカイブができる、シンプルなブログです。

- ✅ 記事を書いて公開する
- ✅ 記事を読む
- ✅ 記事を編集する
- ✅ 記事を削除する
- ✅ 月別アーカイブで絞り込む
- ✅ インターネットに公開する

## 使用するバージョン

このガイドは以下のバージョンを前提に書かれています。

| ツール | バージョン | 役割 |
|--------|-----------|------|
| PHP | 8.5 | プログラムを動かす言語（Laravel 13 は 8.3 以上が必要） |
| Laravel | 13.x | アプリの土台になるフレームワーク |
| SQLite | 3 | 記事を保存するデータベース |
| Node.js | 24 (LTS) | CSS / JavaScript を組み立てる道具 |
| Tailwind CSS | v4 | 見た目を整える CSS の道具 |
| Vite | 8 | CSS / JavaScript をまとめるツール |

> ⚠️ ネットで見つかる記事は Laravel 10 / 11 / 12 のものが多く、書き方が違う場合があります。
> このガイドと違う手順が出てきたら、このガイドを優先してください。
> 公式ドキュメント（日本語）: [https://readouble.com/laravel/13.x/ja/](https://readouble.com/laravel/13.x/ja/)
