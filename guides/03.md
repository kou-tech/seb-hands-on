# インストール・レシピ

アプリ作りの準備として、必要なソフトウェアをインストールしましょう。

## 作業時間の目安

- **実際の作業時間** 約5分
- **インストール待ち時間** 15〜30分

インストール中は他のことをしていても大丈夫です。

## 重要なお知らせ

インストールの手順については、**あまり細かく理解しようとしなくて大丈夫**です。
今は「アプリを作る準備」と考えてください。使っていくうちに、それぞれのツールの役割が分かってきます。

⚠️ もしエラーが出たら、**すぐにメンターに相談してください**

## お使いのOSを選んでください

インストール方法はOSによって異なります。該当するものをクリックしてください。

- [macOS](#macos)
- [Windows](#windows)

## macOS

### 1. Homebrewのインストール

Homebrewは、macOS用のパッケージ管理ツールです。

ターミナルを開いて、以下のコマンドを実行してください。

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

パスワードを求められたら、macOSのログインパスワードを入力してください（画面には表示されませんが、入力できています）。

> **メンター視点**
> - 長いコマンドはコピー＆ペーストで入力するよう案内してください
> - ターミナルでのペーストは `Cmd + V` または右クリックから可能です
> - パスワードが画面に表示されないのはセキュリティ上の仕様です。「入力できていないように見えるが、ちゃんと入力されている」と伝えると安心します
> - パスワードを間違えても再度聞かれるので、焦らなくて大丈夫です

### 2. PHPのインストール

```bash
brew install php
```

インストールが完了したら、バージョンを確認しましょう。

```bash
php --version
```

`PHP 8.2` 以上が表示されればOKです。

> **メンター視点**
> - `8.2.x` や `8.3.x` など細かいバージョン番号が異なっていても問題ありません
> - 8.2以上であればOKと伝えてください

### 3. Composerのインストール

Composerは、PHPのパッケージ管理ツールです。

```bash
brew install composer
```

確認

```bash
composer --version
```

### 4. Node.jsのインストール

```bash
brew install node
```

確認

```bash
node --version
npm --version
```

両方のコマンドでバージョン番号が表示されればOKです。

### 5. Visual Studio Codeのインストール

1. [https://code.visualstudio.com/](https://code.visualstudio.com/) にアクセス
2. 「Download for Mac」をクリック
3. ダウンロードしたファイルを開いて、アプリケーションフォルダにドラッグ

### インストール完了！

すべてのツールがインストールできたら、次のステップに進みましょう。

## Windows

### 1. PHPのインストール

#### 1-1. XAMPP（ザンプ）をインストール

XAMPPは、PHPを簡単に使えるようにするパッケージです。

> **メンター視点**
> - XAMPPの中身（Apache, MySQL, PHP, Perl）について深く説明する必要はありません
> - 「今回はPHPだけを使う」と伝えれば十分です

1. [https://www.apachefriends.org/](https://www.apachefriends.org/) にアクセス
2. 「Windows向けXAMPP」をダウンロード
3. ダウンロードしたファイルを実行してインストール
4. インストール先は `C:\xampp` のまま（変更しない）

#### 1-2. 環境変数の設定

PHPをどこからでも使えるようにします。

> **メンター視点**
> - 「環境変数とは何か」の説明は不要です。手順通りに進めることを優先してください
> - 画面を一緒に見ながら進めると、迷わずに設定できます
> - この手順は初心者にとって難しい部分なので、ゆっくり丁寧に進めてください

1. スタートメニューで「環境変数」と検索
2. 「システム環境変数の編集」をクリック
3. 「環境変数」ボタンをクリック
4. 「システム環境変数」の「Path」を選んで「編集」
5. 「新規」をクリックして `C:\xampp\php` を追加
6. 「OK」で閉じる

**確認** PowerShellを**新しく開いて**以下を実行

```powershell
php --version
```

`PHP 8.2` 以上が表示されればOKです。

> **メンター視点**
> - 「新しく開いて」を強調してください。古いウィンドウでは環境変数の変更が反映されません
> - `8.2.x` や `8.3.x` など細かいバージョン番号が異なっていても問題ありません

### 2. Composerのインストール

1. [https://getcomposer.org/download/](https://getcomposer.org/download/) にアクセス
2. 「Composer-Setup.exe」をダウンロード
3. インストーラーを実行
4. すべてデフォルト設定のまま進める

**確認** PowerShellを**新しく開いて**

```powershell
composer --version
```

### 3. Node.jsのインストール

1. [https://nodejs.org/](https://nodejs.org/) にアクセス
2. 「LTS」版（推奨版）をダウンロード
3. ダウンロードしたインストーラー（`.msi`ファイル）を実行
4. インストール中、以下のオプションが有効になっていることを確認：
   - 「npm package manager」にチェックが入っている
   - 「Add to PATH」にチェックが入っている
5. その他はデフォルト設定のまま進める

**確認** PowerShellを**新しく開いて**

```powershell
node --version
npm --version
```

両方のコマンドでバージョン番号が表示されればOKです。

### 4. Visual Studio Codeのインストール

1. [https://code.visualstudio.com/](https://code.visualstudio.com/) にアクセス
2. 「Download for Windows」をクリック
3. ダウンロードしたファイルを実行してインストール

### インストール完了！

すべてのツールがインストールできたら、次のステップに進みましょう。

## よくあるエラー

### 「コマンドが見つかりません」と表示される

**原因** ターミナル（PowerShell）を閉じていない

**解決方法** ターミナルを**完全に閉じて、新しく開き直してください**

環境変数の変更は、新しく開いたターミナルでのみ反映されます。

### Homebrewのインストールが失敗する（macOS）

**解決方法** メンターに相談してください

Xcodeのコマンドラインツールのインストールが必要な場合があります。

> **メンター視点**
> - 以下のコマンドでXcodeコマンドラインツールをインストールできます
> - `xcode-select --install`
> - Apple IDでのサインインを求められる場合があります

### PowerShellでスクリプトが実行できない（Windows）

**症状** 「このシステムではスクリプトの実行が無効になっているため...」というエラーが表示される

**原因** PowerShellの実行ポリシーがスクリプトをブロックしています

**解決方法**
1. PowerShellを**管理者として実行**（右クリック→「管理者として実行」）
2. 以下のコマンドを入力してEnter

```powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
```

3. 「Y」を入力してEnter
4. PowerShellを閉じて、通常のPowerShellを開き直す

> **メンター視点**
> - この設定はセキュリティレベルを少し緩めるものですが、開発作業には一般的な設定です
> - 不安がある場合は、設定の意味を簡単に説明してあげてください

### 「git was not found」という警告が出る

**症状** `composer create-project` や `npm install` の実行中に「git was not found in your PATH」のような警告が表示される

**これはエラーではありません**

ComposerやnpmがGitを探しましたが見つからなかった、という情報メッセージです。この段階ではGitは必須ではないため、**警告は無視して進めて大丈夫**です。

Gitは [GitHubでコードを公開しよう](./06.md) のステップで導入します。

> **メンター視点**
> - 赤いメッセージでも「warning」や「info」と書いてあれば、処理は続行されます
> - 「error」と書いてあり処理が止まった場合のみ対応が必要です

### どうしてもうまくいかない場合

**重要** 遠慮なくメンターに相談してください！

環境構築は初心者にとって最も難しい部分の一つです。プロのエンジニアでも、環境構築で時間がかかることがあります。
